# Platonus Grade Checker Bot

Telegram-бот для автоматического получения и отслеживания оценок студента из образовательной системы Platonus.

## Описание
Этот бот позволяет студенту по нажатию одной кнопки получать актуальную информацию о своих оценках напрямую из Платонуса. Он авторизуется в системе под вашими учетными данными, парсит страницу с оценками и присылает результат в удобном виде в Telegram.

## Стек технологий
- **Язык:** Python 3
- **Бот:** `aiogram` (асинхронная библиотека для Telegram API)
- **Парсинг:** `httpx` (асинхронные запросы), `BeautifulSoup4` (обработка HTML)
- **Деплой:** Docker, Docker Compose

## Структура проекта
- `main.py` — Точка входа, запуск Telegram-бота.
- `bot_handler.py` — Хэндлеры (обработчики) команд и кнопок бота (например, кнопки "Мои оценки").
- `parser.py` — Логика авторизации и парсинга оценок с сайта Platonus.
- `db_api.py` — Модуль для работы с базой данных (если требуется сохранять состояния/пользователей).
- `config.py` — Файл конфигурации для удобного доступа к переменным окружения.
- `Dockerfile` / `docker-compose.yml` — Файлы для сборки и развертывания проекта в Docker-контейнере.
- `requirements.txt` — Список зависимостей Python.

## Настройка и установка

### 1. Переменные окружения
Создайте файл `.env` в корневой папке проекта и добавьте туда следующие переменные:
```env
TELEGRAM_TOKEN=твой_токен_от_BotFather
SERVER_URL=ссылка вашего сервера
FERNET_KEY=твой_fernet_ключ
```

### 1.1 Генерация Fernet-ключа
Если код использует Fernet для шифрования, сгенерируйте ключ командой:
```bash
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```
Скопируйте результат в `FERNET_KEY`.
```

### 2. Запуск локально (без Docker)
Убедитесь, что у вас установлен Python 3.8 или выше.
```bash
# Создание вирутального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

### 3. Запуск через Docker
Если у вас установлен Docker и Docker Compose:
```bash
docker-compose up -d --build
```
Бот будет работать в фоновом режиме.
